Paper3

Traducción de PDFs a lenguaje accesible y síntesis de voz impulsada por IA.

Paper3 es una aplicación web centrada en la democratización del conocimiento y la accesibilidad. Esta herramienta toma documentos complejos en formato PDF y los traduce a un lenguaje accesible en español, facilitando la comprensión de textos técnicos o académicos.

Privacidad y Seguridad desde el Diseño: La plataforma requiere una clave API de Gemini (Google AI Studio). Para garantizar la máxima seguridad, esta clave no se guarda en ninguna base de datos; se almacena de forma local en tu propio navegador.
¿Cómo conseguir una API Key? Puedes generarla de forma gratuita accediendo a Google AI Studio con tu cuenta de Google.

Accesibilidad Multimodal: Una vez que el documento es traducido, puedes utilizar la función de Web Speech API integrada (propia de tu navegador, sin generar costos adicionales) para escuchar el texto. Además, si lo deseas, puedes descargar el audio generado directamente como un archivo MP3 para escucharlo donde quieras.
