Paper3

AI-powered translation of PDFs into accessible language with voice synthesis.

Paper3 is a web application focused on the democratization of knowledge and accessibility. This tool takes complex PDF documents and translates them into accessible language in Spanish, making technical or academic texts much easier to understand.

Privacy and Security by Design: The platform requires a Gemini API key (Google AI Studio). To ensure maximum security, this key is never stored in any database; it is kept locally and securely within your own browser.
How to get an API Key? You can generate one for free by accessing Google AI Studio with your Google account.

Multimodal Accessibility: Once the document is translated, you can use the built-in Web Speech API function (native to your browser, generating no additional costs) to listen to the text. Furthermore, if you wish, you can download the generated audio directly as an MP3 file to listen to wherever you want.
